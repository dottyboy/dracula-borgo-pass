# Props (everything that is not a building)

## 6. Props (anything that is not a building)

Template:
```
A single <object>, <material and age>, Victorian gothic style, shown from a three-quarter front view on a flat light-green
background, whole object visible with space around it, photorealistic, even lighting, high detail, no other objects.
```

Pick from the game ids (add a short description; keep the same wording across variants so image-to-3D gets a similar object):

| group | ids |
|---|---|
| furniture | table, table_long, chair, bench, bed, bed_simple, bookshelf, chest, throne, rug, mirror (ornate), fireplace, coffin, tomb |
| lights | candle, candelabra, lantern (iron, lit), sconce, lamp_post (gas street lamp) |
| items and relics | key (big iron), crucifix, crucifix_big, hammer, stake (wooden), garlic (bulbs), goblet, bottle, book, bust (marble), a3_clock, a3_bag (doctor's bag), a3_phonograph (wax cylinder), a6_earth_box (earth chest) |
| doors and walls | door, door_big, arch, column, column_short, stairs, wall_4 (stone wall panel), signpost, inn_sign |
| nature | pine, pine_small, oak, yew, deadtree, bush, shrub, fern, hedge, flower_patch, reeds, rock, rock_big, boulders, log, stump |
| graveyard | gravestone, gravestone_point, grave_cross, tomb |
| harbour | boat, anchor, bollard, net_rack, rope_coil, crate_stack, barrel, pier, quay_edge, mast_cluster, lighthouse (tower form), a2_schooner / demeter_voyage_schooner, a6_brig, a6_launch, a2_wheel |
| village | cart, a6_leiter_wagon (farm wagon), carriage, hay_bale, well, market_stall, picket_fence, fence, low_wall |

Notes for props: one object per image; no table under a table-top item; for doors and arches ask for a straight frontal view.
