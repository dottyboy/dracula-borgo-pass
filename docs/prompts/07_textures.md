# Textures

## 7. Textures (seamless, albedo only)

Template:
```
Seamless tileable texture, top-down flat orthographic view, no perspective, no shadows, no lighting gradient, even
illumination, <material>, 1024x1024, photorealistic PBR albedo/base colour map.
```
In the tool: switch on "tiling / seamless" if it exists. Check by tiling 2 x 2 in an image viewer; fix seams with Blender/GIMP "make seamless".

| id (game) | description to put in `<material>` |
|---|---|
| stone_blocks | old grey cut-stone block wall with dark mortar, castle masonry |
| stone_moss | the same stone with green moss in the joints, damp |
| stone_rough | rough unworked grey stone, uneven, cave or crypt walls |
| cobble | wet cobblestone street, rounded grey and brown stones, dark gaps |
| wood_planks | aged oak floor planks, dark brown, nail heads, worn |
| plaster | cracked lime-wash plaster wall, warm cream and grey |
| cloth | coarse woven linen, off-white |
| wool | heavy dark wool cloth, visible knit twill |
| velvet | deep crimson velvet, soft nap |
| leather | worn brown leather with creases |
| iron | dark wrought iron, rust specks, hammered |
| gold | tarnished brass/gold, scratched |
| glass | dirty old window glass, faint bubbles |
| wax | pale yellow candle wax, smooth |
| flame | (skip: generated in code) |
| parchment | aged parchment, yellowed, stains |
| dirt | dry brown earth path, small stones |
| bark | rough dark conifer bark |
| foliage | dense dark-green conifer needles |
| grass | short dark-green meadow grass, some dry blades |
| snow | clean trampled snow, blue-white shadows in the grain |
| fur | thick grey animal fur, individual strands |
| hair | dark brown hair strands, glossy (or blond variant) |
| skin | human skin, pale, subtle pores (for faces we use the models' own textures) |
| flat | (skip: plain colour) |

wallpaper (damask green / burgundy), marble floor tiles (black and white), cliff rock, sand, water foam.
