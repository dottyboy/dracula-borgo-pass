# Prompts for external AI: characters, creatures, props, textures

Everything here can be pasted into an image generator (then an image-to-3D tool for models). Buildings are **not** in
this list: the game builds them itself. Style target: photorealistic, dark Victorian gothic, Bram Stoker's *Dracula* (1897).

## 0. Pipeline in one glance

```
prompt -> image (green background) -> image-to-3D (GLB, textured) -> rig_ai.py (humans) / import as prop -> game
```

* Folder for sources: `ai/<kind>/<id>.png` and `ai/<kind>/<id>.glb` (kinds: `characters`, `creatures`, `props`, `textures`).
  Keep the file name equal to the game id from the tables below.
* Humans: `blender -b -P pipeline/mixamo/rig_ai.py -- ai/characters/<id>.glb "pipeline/mixamo/Y Bot.fbx" assets/models/chars/sk_<model>_<variant>.glb 1.9 35000`
  (arms-down or T-pose both work; the script poses a Y Bot to the mesh, copies weights and binds the Mixamo skeleton).
* Props and creatures: static GLB, decimate to <= 15 k triangles, keep one 1024-2048 px texture.
* Textures: 1024 x 1024, seamless, albedo only (normals are generated by our pipeline from height).
* **Licence:** before anything made with an AI tool goes into the public repository or a release, check that tool's terms for
  output (commercial use, redistribution). Record tool, date and licence in `ai/SOURCES.md` next to the file.

## 1. Reusable blocks (paste before / after the per-item description)

**CHARACTER_PREFIX**
```
A full-body shot, shot from head to toe, standing posture T-POSE, including whole boots and little spacing on bottom margin,
A full-body portrait of
```

**CHARACTER_SUFFIX**
```
Standing head-to-toe T-POSE, arms straight out to the sides, hands open with fingers apart, legs slightly apart, neutral
relaxed face, nothing held in the hands, in front of a flat light-green background, photoshoot lighting from all angles,
photorealistic, intricate details, even shadowless lighting.
```

**NEGATIVE** (for tools that have a negative prompt)
```
cropped, cut off feet, close-up, three-quarter shot, holding objects, walking stick, crossed arms, arms down, hands in pockets,
long cape covering the body, long hair covering the face, text, watermark, multiple people, busy background, cartoon, anime,
low resolution, extra fingers, deformed hands
```

Why these changes to your first prompts (what we learned rigging `DraculaOld`): a true **T-pose with nothing in the hands** and
**a cape that does not cover the body** makes skin weights clean. Capes, coat tails and skirts are better added by our cloth
system (chain bones) than baked into the mesh: ask for the cape as a **separate prompt variant** ("shown without the cape") or
a short one, and keep the long coat open at the front only if the legs still show.

## 8. Quality checklist before an image goes to 3D

* Whole body or object inside the frame, feet and hands visible, flat uniform background (green), no ground shadow.
* Humans: T-pose or straight arms-down A-pose, hands open, no props, symmetrical, neutral face.
* One subject. If the tool made a "turnaround sheet", crop one view.
* Keep prompts identical apart from the description so style and proportions stay consistent between characters.
* After 3D: check back and side views before spending time on rigging; regenerate rather than repair bad backs or hands.
* Save prompt, seed and tool name next to each file (`ai/SOURCES.md`).
